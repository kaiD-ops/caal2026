🎯 LAYER IMPLEMENTATION DETAILS
════════════════════════════════════════════════════════════════════════════════

LAYER 1: HILBERT SCAN (6 pts) ✅
├─ Algorithm: Nested loop reordering using pre-computed Hilbert indices
├─ Input: (C_IN, 64, 64) image → Output: (4096, C_IN) sequence
├─ Complexity: O(4096) - pure integer indexing, NO floating-point
├─ Register Usage: s0-s7 (callee-saved)
├─ Expected MSE: < 1e-12 (exact match)
└─ Status: Ready for testing ✅

LAYER 2: LINEAR LAYER (6 pts) ✅
├─ Algorithm: Triple-nested loop: for t, o, i → output[t,o] += weight[o,i] * input[t,i]
├─ Use Cases: UProject (4096×1)→(4096×64) & FC Head (64)→(4)
├─ Complexity: O(seq_len × out_dim × in_dim)
├─ Float Ops: flw, fmul.s (or fmadd.s), fadd.s, fsw
├─ Register Usage: s0-s11, f0-f3 (temporaries), fs0-fs11 (if used)
├─ Expected MSE: < 1e-6 (float32 precision)
└─ Status: Ready for testing ✅

LAYER 3: TAKE LAST TIMESTEP (3 pts) ✅
├─ Algorithm: Extract row at offset (4095 × 64 × 4) bytes
├─ Input: (4096, 64) sequence → Output: (64,) vector
├─ Complexity: O(64) - simple unrolled copy
├─ Implementation: 64-iteration loop with flw/fsw
├─ Expected MSE: < 1e-12 (exact copy/match)
└─ Status: Ready for testing ✅

LAYER 4: SOFTMAX (3 pts) ✅
├─ Algorithm: 1. Find max 2. Shift & exp 3. Sum 4. Normalize
├─ Input/Output: (4,) probabilities in-place
├─ Complexity: O(4) main loop + O(exp) from Member 2
├─ Numerically Stable: Subtracts max before exp to prevent overflow
├─ Dependencies: exp() function from Member 2 (to be coordinated)
├─ Output Constraint: Probabilities sum to 1.0 ± 1e-6
├─ Expected MSE: < 1e-6
└─ Status: Ready for testing (pending Member 2 exp) ✅
